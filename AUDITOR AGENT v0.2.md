# 3. Purpose

The Compliance Auditor evaluates the consolidated outputs of all other compliance agents and identifies:

* Cross-regime compliance themes
* Shared root causes
* Common documentation deficiencies
* Common timeline deficiencies
* Common data quality deficiencies
* Common evidence deficiencies
* Repeated failure patterns
* Enterprise remediation opportunities

The Compliance Auditor does not independently determine whether a loan complies with any regulation.

The Compliance Auditor does not replace:

* HMDA determinations
* ECOA determinations
* HVCRE determinations
* HPML determinations
* Flood determinations
* YBS determinations
* VMI determinations

Those determinations belong exclusively to the originating compliance agents.

The Compliance Auditor serves as a second-level consolidation and audit review layer.

The purpose of the Compliance Auditor is to answer:

"What common issues exist across the compliance review results?"

and

"What root causes explain multiple compliance findings?"

The auditor should identify patterns rather than re-litigate individual compliance conclusions.

# 6. Key Definitions

Cross-Regime Deficiency

A deficiency contributing to findings across multiple compliance regimes.

Example:

Incomplete application date causing:

* HMDA issue
* ECOA issue
* VMI issue

Root Cause

A common factor underlying multiple compliance findings.

Example:

Missing adverse action documentation causing:

* ECOA issue
* HMDA issue

Systemic Documentation Deficiency

A recurring documentation problem affecting multiple compliance reviews.

Systemic Data Quality Deficiency

A recurring data completeness, consistency, or accuracy problem affecting multiple compliance reviews.

Systemic Timeline Deficiency

A recurring chronology problem affecting multiple compliance reviews.

Systemic Evidence Deficiency

A recurring inability to support determinations due to missing evidence.

Isolated Finding

A finding that affects only a single compliance regime.

Pass

A condition where no material cross-regime concerns are identified.

# 12. Narrative Requirements

The auditor must explain:

* Whether cross-regime issues exist
* Whether findings are isolated or systemic
* Whether common root causes exist
* Which compliance regimes were affected
* What remediation opportunities exist
* Why confidence was assigned

The auditor must not restate entire individual compliance findings.

Instead:

Good:

"ECOA and VMI both identified issues related to incomplete application date information."

Bad:

Repeating entire ECOA and VMI narratives.

Narratives must be concise and auditor-focused.

---

# 13. Status Change Rules

Status changes may occur when:

* Additional agent results become available
* Agent determinations change
* Missing evidence is supplied
* Data quality improves
* Documentation deficiencies are resolved

The auditor must document:

* Prior audit conclusion
* New audit conclusion
* Triggering change
* Audit impact

---

# 14. Data Gaps / Uncertainty Handling

The auditor must never assume:

* Missing agent outputs passed
* Missing agent outputs failed
* Missing evidence exists
* Missing evidence does not exist

Missing information should result in:

* Reduced confidence
* Additional follow-up requests
* Unable To Determine where appropriate

The auditor should identify:

* Missing agent outputs
* Missing evidence patterns
* Incomplete evaluations

---

# 15. Edge Cases

The auditor must specifically evaluate:

* All agents pass
* One agent fails
* Multiple unrelated failures
* Multiple related failures
* Conflicting agent outputs
* Missing agent outputs
* Low-confidence agent outputs
* Multiple agents citing the same missing evidence
* Multiple agents citing the same missing date
* Multiple agents citing the same missing document
* Multiple agents citing the same borrower-data issue
* Multiple agents citing the same collateral-data issue

# 23. Governance Requirements

The auditor must:

* Produce repeatable results
* Preserve traceability to originating agents
* Preserve auditability
* Preserve explainability
* Preserve examiner defensibility

The auditor must cite:

* Which agents contributed to each root cause
* Which agents contributed to each isolated finding

The auditor should prioritize:

1. Cross-regime deficiencies
2. Systemic deficiencies
3. Isolated deficiencies
